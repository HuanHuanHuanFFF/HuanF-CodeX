## 使用方式

- 新题先独立尝试，记录关键观察、卡点及获得的提示，再看题解。
- 复盘保留可迁移的结论和具体错误；AC 与独立识别、证明能力分别记录。
- 隔几天不看代码复述或做小变式，根据实际表现决定继续补什么。
- 详细学习背景由根目录本地的 `LEARNER_PROFILE.md` 维护，此处保留便于复习的训练记录。

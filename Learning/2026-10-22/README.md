## ABC247E — Max Min

- [代码](ABC247E.cpp) · [题目](https://atcoder.jp/contests/abc247/tasks/abc247_e)
- 结果：用户报告 AC；归档时已读取实现。
- 完成边界：首次没有思路，经逐步提示完成建模后实现；不能据此认为已能独立识别。

固定右端点 R，记录最近的 X、Y 的位置 p、q，以及最近越界位置 b。合法左端点满足 `b < L <= min(p,q)`，贡献为 `max(0,min(p,q)-b)`。实现用 INF 表示端点值未出现，并显式检查位置后累加，答案使用 long long。

本次卡点是将“必须同时包含 X、Y”转为左端点约束，曾把 min 说成 max。最近出现位置给出的合法范围包含更早位置能提供的范围，因此无需保存全部历史位置。后一个解释由助手补充；后续用新题复查自主建模。

## CF1611E1 / E2 — Escape The Maze

- [E1 代码](CF1611E1.cpp) · [题目](https://codeforces.com/contest/1611/problem/E1) · [AC 提交](https://codeforces.com/contest/1611/submission/395586691)
- [E2 代码](CF1611E2.cpp) · [题目](https://codeforces.com/contest/1611/problem/E2) · [AC 提交](https://codeforces.com/contest/1611/submission/395590096)
- 结果：浏览器个人提交表核实两版 Accepted；已读取两份本地代码，提交详情页遇安全验证，未逐字对照平台源码。
- 完成边界：未提供算法提示，用户自主完成两版；过程中仅讨论 vector 的 move、swap。用户能指出树上唯一路径与朋友朝根拦截，完整最优性证明未独立复述。

先从全部朋友同时 BFS，得到每点最近朋友距离。再从 1 搜索，当前深度不小于朋友距离时立即停止；相等也会被抓。找到安全叶子则可以逃脱。

E2 沿用 E1 的剪枝位置，每次首次被拦截时计数。一个这样的子树可由一个朋友封住；不同剪枝子树需要各自的朋友。若某朋友在主角之前无法到达某子树的入口，就不可能从其他分支绕到其中拦截，因为树上路径唯一。

叶子比较为何能说明途中安全：若朋友能不晚于主角到达中途点，再沿剩余路线前往叶子，也能不晚于主角到达。因此主角严格更早到叶子时，途中不会被截住。此论证由助手补充。

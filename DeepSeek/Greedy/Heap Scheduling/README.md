# 堆调度贪心

共同结构：扫描时间或数值位置，加入所有已满足进入条件的候选，用堆选择当前最优项。每次安排一个后，重新检查新候选；没有候选时可跳过空白位置。

| 题目 | 堆中维护 | 优先选择 | 关键区别 |
| --- | --- | --- | --- |
| [ABC214E](ABC214E.cpp) | 右端点 | 最早到期 | 必须全部安排，过期即无解 |
| [LC1353](LC.1353.cpp) | 结束日 | 最早结束 | 求最多参加数量，过期可丢弃 |
| [ABC325D](ABC325D.cpp) | 截止时间 | 最早到期 | 截止时刻可打印，过期条件为 `r < x` |
| [LC1705](LC.1705.cpp) | 腐烂日、剩余数量 | 最早腐烂 | 腐烂当天不可吃，过期条件为 `expire <= day` |
| [CF1310A](1310A.cpp) | 单位代价、原值 | 单位代价最大 | 尽早安排等待代价高的项，费用为 `(x-a)*cost` |

## 复习要点

- 入堆条件决定“现在能选谁”，堆的顺序决定“先选谁”。先推导选择依据，再决定用大根堆还是小根堆。
- 最早截止优先：已经到达的两个任务交换位置，较晚截止者能接替较早截止者的后续位置。
- 最大单位代价优先：两个候选交换时，让代价大的提前，可减少总等待费用。
- 每次只处理一个有效项；全部过期项可以连续清理。
- 数组耗尽后堆可能仍有内容，先检查下标，再访问数组。

复习顺序：先脱离代码说出“候选、优先级、端点含义”，再手推一个例子，最后检查实现。
